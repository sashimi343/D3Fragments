# OpenAPI

The `Sashimi343.D3Fragments.AspNetCore.OpenApi` package aligns the OpenAPI documents generated by `Microsoft.AspNetCore.OpenApi` with the JSON representation of the D3Fragments types.

## Usage

Call `AddD3Fragments` when configuring `AddOpenApi`.

```csharp
builder.Services.AddOpenApi(options => options.AddD3Fragments());
```

The following schemas are always transformed.

| Type | Resulting schema |
|---|---|
| `UuidV7` | A string in the `uuid` format |
| Value objects | The schema of the wrapped type (such as `string`) |
| Type-safe enums | A key or name schema that lists the defined values, following the `TypeSafeEnumJsonConverterFactory` registered in the JSON options. Not transformed if the converter is not registered |

Value object constraints (such as maximum length) are implemented in the `ValidateValue` code, so they are not reflected in the schema.

## Options

```csharp
builder.Services.AddOpenApi(options => options.AddD3Fragments(o =>
{
    o.DescribeEnumValues = true;
    o.IncludeCsrfProtectionHeader = true;
}));
```

| Property | Description | Default |
|---|---|---|
| `DescribeEnumValues` | Appends the list of defined values (number, name, display name) to the description of enum schemas | `false` |
| `IncludeCsrfProtectionHeader` | Adds the header required by the [CSRF protection](03-csrf.md) middleware to the operations it checks. The header name, the methods that are not checked, and the excluded paths follow `CsrfProtectionOptions` | `false` |
