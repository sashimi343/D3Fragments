# DFR0009: エンティティは変更可能なコレクションを公開すべきではありません

| プロパティ | 値 |
|---|---|
| 規則 ID | DFR0009 |
| タイトル | エンティティは変更可能なコレクションを公開すべきではありません |
| 既定の重大度 | Warning |
| 修正が破壊的か非破壊的か | 破壊的 |
| コード修正 | なし |

## 原因

`D3Fragments.EntityBase<TId>` クラスを直接、または間接的に継承したクラスにおいて、型が変更可能なコレクションであるプロパティまたはフィールドが、以下のアクセシビリティで宣言されています。

- プロパティ：`get` アクセサーのアクセシビリティが `public` / `internal` / `protected internal`
- フィールド：アクセシビリティが `public` / `internal` / `protected internal`（`readonly` かどうかは問わない）

変更可能なコレクションとは、以下のいずれかに該当する型です。

- 配列
- `System.Collections.Generic.ICollection<T>` または `System.Collections.Generic.IDictionary<TKey, TValue>` であるか、それらを実装した型（`List<T>`、`IList<T>`、`HashSet<T>`、`Dictionary<TKey, TValue>` 等）

ただし、以下の型は変更可能なコレクションとみなしません。

- `System.Collections.ObjectModel.ReadOnlyCollection<T>`、`ReadOnlyDictionary<TKey, TValue>`、`ReadOnlySet<T>`、`ReadOnlyObservableCollection<T>`
- `System.Collections.Immutable` 名前空間の型

セッターのアクセシビリティは問いません。クラス自体のアクセシビリティ、明示的なインターフェイス実装、違反の報告箇所の扱いは [DFR0003](DFR0003.md) と同じです。

`IReadOnlyList<T>` などの読み取り専用インターフェイス型として公開したプロパティが、内部で `List<T>` のインスタンスを返し、利用側でキャストして変更されるケースは本規則では検知できません。

本規則はアセンブリのアーキテクチャ層の設定（`ArchitectureLayerAttribute`）に関係なく検証されます。

## 規則の説明

エンティティの状態の変更は操作（メソッド）により行われるべきです。
変更可能なコレクションを公開すると、セッターを非公開にしても、利用側が `Add` / `Remove` 等のコレクション操作でエンティティの状態を変更できてしまい、[DFR0003](DFR0003.md) と同様の問題が発生します。

## 違反の修正方法

コレクションは `private` なフィールドで保持し、`IReadOnlyList<T>` や `IReadOnlyCollection<T>` などの読み取り専用インターフェイス型で公開してください。
コレクションの変更はエンティティの操作（メソッド）として実装してください。

## 例

```csharp
public class Bookshelf : AggregateRoot<UuidV7>
{
    // Violates DFR0009
    public List<Book> Books { get; private set; } = [];
}
```

```csharp
public class Bookshelf : AggregateRoot<UuidV7>
{
    private readonly List<Book> _books = [];

    // Does not violate DFR0009
    public IReadOnlyList<Book> Books => _books;

    public void AddBook(Book book)
    {
        ...
        _books.Add(book);
    }
}
```

## 警告を抑制する状況

一般に、この規則による警告は抑制しないでください。

## 警告を抑制する

単一の違反を抑制するだけの場合は、ソース ファイルにプリプロセッサ ディレクティブを追加して無効にしてから、規則をもう一度有効にします。

```csharp
#pragma warning disable DFR0009
// 規則に違反するコード
#pragma warning restore DFR0009
```

ファイル、フォルダー、プロジェクトの規則を無効にするには、その重要度を `none` に設定し、[設定ファイル](https://learn.microsoft.com/ja-jp/dotnet/fundamentals/code-analysis/configuration-files) で適用します。

```ini
[*.cs]
dotnet_diagnostic.DFR0009.severity = none
```
