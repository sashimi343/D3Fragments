# DFR0004: 集約の一部を取得するリポジトリメソッドを定義しないでください

| プロパティ | 値 |
|---|---|
| 規則 ID | DFR0004 |
| タイトル | 集約の一部を取得するリポジトリメソッドを定義しないでください |
| 既定の重大度 | Warning |
| 修正が破壊的か非破壊的か | 破壊的 |
| コード修正 | なし |

## 原因

`D3Fragments.IRepository<TAggregate, TId>` インターフェースを直接、または間接的に継承したインターフェース（`IRepository<TAggregate>` を経由した継承を含む）において、戻り値の型に `TAggregate` 以外のエンティティ（`EntityBase<TId>` を直接、または間接的に継承したクラス）を含むメソッドが宣言されています。

戻り値の型は以下のように再帰的に検査され、いずれかに該当する型が含まれていれば違反となります。

- 戻り値の型そのもの
- 配列の要素型
- ジェネリック型の型引数（`Task<T>`、`ValueTask<T>`、`IAsyncEnumerable<T>`、`IReadOnlyList<T>`、`Dictionary<TKey, TValue>`、`Result<T>`、タプル等。入れ子の型引数も含む）

以下の点に注意してください。

- `TAggregate` を直接、または間接的に継承したクラスは違反となりません。
- `TAggregate` 以外の集約ルート（別の集約）も違反となります。別の集約は、その集約のリポジトリから取得してください。
- 検査対象は、そのインターフェースで宣言されたメソッドです（継承元のインターフェースのメソッドは、継承元のインターフェースで検査されます）。
- リポジトリの実装クラスで追加されたメソッドは検査されません。

本規則はアセンブリのアーキテクチャ層の設定（`ArchitectureLayerAttribute`）に関係なく検証されます。

## 規則の説明

リポジトリ経由でのエンティティの取得は集約単位で実施されるべきです。
集約の一部のエンティティのみを返すメソッドを実装した場合、集約の整合性が壊れる可能性があります。

## 違反の修正方法

集約の一部ではなく、集約ルート自体を返すように変更してください。
画面表示などの参照用途で集約の一部のデータのみが必要な場合は、エンティティではなく参照用のDTOを返すクエリを別途用意してください。

## 例

```csharp
public class Bookshelf : AggregateRoot<UuidV7>
{
    public IReadOnlyList<Book> Books => _books;
    ...
}

public class Book : Entity<UuidV7> { ... }

public interface IBookshelfRepository : IRepository<Bookshelf, UuidV7>
{
    // Violates DFR0004
    Task<IReadOnlyList<Book>> FindBooksAsync(UuidV7 bookshelfId, CancellationToken cancellationToken);
}
```

```csharp
public interface IBookshelfRepository : IRepository<Bookshelf, UuidV7>
{
    // Does not violate DFR0004
    Task<IReadOnlyList<Bookshelf>> FindByOwnerAsync(UuidV7 ownerId, CancellationToken cancellationToken);
}
```

## 警告を抑制する状況

一般に、この規則による警告は抑制しないでください。

## 警告を抑制する

単一の違反を抑制するだけの場合は、ソース ファイルにプリプロセッサ ディレクティブを追加して無効にしてから、規則をもう一度有効にします。

```csharp
#pragma warning disable DFR0004
// 規則に違反するコード
#pragma warning restore DFR0004
```

ファイル、フォルダー、プロジェクトの規則を無効にするには、その重要度を `none` に設定し、[設定ファイル](https://learn.microsoft.com/ja-jp/dotnet/fundamentals/code-analysis/configuration-files) で適用します。

```ini
[*.cs]
dotnet_diagnostic.DFR0004.severity = none
```
