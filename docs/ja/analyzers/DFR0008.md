# DFR0008: TypeSafeEnum の値は static readonly フィールドで定義してください

| プロパティ | 値 |
|---|---|
| 規則 ID | DFR0008 |
| タイトル | TypeSafeEnum の値は static readonly フィールドで定義してください |
| 既定の重大度 | Warning |
| 修正が破壊的か非破壊的か | 破壊的 |
| コード修正 | なし |

## 原因

本規則では、基底クラスとして `D3Fragments.TypeSafeEnum<TSelf, TKey>` を直接指定したクラスを「TypeSafeEnum 型」と呼びます。ただし、`TSelf` が型パラメーターであるクラス（ジェネリックな中間基底クラス）は TypeSafeEnum 型に含みません。

TypeSafeEnum 型の宣言内（入れ子クラスを含む）で、以下のいずれかに該当する場合に違反となります。

- TypeSafeEnum 型（またはその派生クラス）のインスタンス生成（`new` 式。target-typed `new` を含む）が、TypeSafeEnum 型の `static readonly` フィールドの初期化子以外の場所にある
  - 例：静的プロパティの式本体（`static X => new(...)`）、自動実装プロパティの初期化子（`static X { get; } = new(...)`）、メソッド内
- 型が TypeSafeEnum 型（またはその派生クラス）である静的フィールドが `readonly` ではない

本規則はアセンブリのアーキテクチャ層の設定（`ArchitectureLayerAttribute`）に関係なく検証されます。

## 規則の説明

TypeSafeEnum 型の値は、インスタンスの生成時にキーと名前が登録され、各値は単一のインスタンスとして存在することを前提としています。

- 静的プロパティの式本体などで値を生成すると、アクセスするたびに新しいインスタンスが生成され、キーの重複により `ArgumentException` が発生します。
- `readonly` ではない静的フィールドで値を定義すると、定義済みの値を別のインスタンスに差し替えることができてしまいます。

## 違反の修正方法

値は TypeSafeEnum 型の `static readonly` フィールドとして定義してください。

## 例

```csharp
public class UserType : TypeSafeEnum<UserType, int>
{
    // Violates DFR0008
    public static UserType Normal => new(0, "一般ユーザ");

    // Violates DFR0008
    public static UserType Admin = new(1, "管理ユーザ");

    private UserType(int key, string name) : base(key, name) {}
}
```

```csharp
public class UserType : TypeSafeEnum<UserType, int>
{
    // Does not violate DFR0008
    public static readonly UserType Normal = new(0, "一般ユーザ");
    public static readonly UserType Admin = new(1, "管理ユーザ");

    private UserType(int key, string name) : base(key, name) {}
}
```

## 警告を抑制する状況

この規則による警告は抑制しないでください。

## 警告を抑制する

単一の違反を抑制するだけの場合は、ソース ファイルにプリプロセッサ ディレクティブを追加して無効にしてから、規則をもう一度有効にします。

```csharp
#pragma warning disable DFR0008
// 規則に違反するコード
#pragma warning restore DFR0008
```

ファイル、フォルダー、プロジェクトの規則を無効にするには、その重要度を `none` に設定し、[設定ファイル](https://learn.microsoft.com/ja-jp/dotnet/fundamentals/code-analysis/configuration-files) で適用します。

```ini
[*.cs]
dotnet_diagnostic.DFR0008.severity = none
```
