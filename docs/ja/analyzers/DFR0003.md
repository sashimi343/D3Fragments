# DFR0003: エンティティクラスは公開セッターをもつべきではありません

| プロパティ | 値 |
|---|---|
| 規則 ID | DFR0003 |
| タイトル | エンティティクラスは公開セッターをもつべきではありません |
| 既定の重大度 | Warning |
| 修正が破壊的か非破壊的か | 破壊的 |
| コード修正 | あり（プロパティのみ） |

## 原因

`D3Fragments.EntityBase<TId>` クラスを直接、または間接的に継承したクラスにおいて、以下のいずれかのメンバーが宣言されています。

- アクセシビリティが `public` / `internal` / `protected internal` の `set` アクセサーまたは `init` アクセサーをもつプロパティ
- アクセシビリティが `public` / `internal` / `protected internal` で、`readonly` ではないフィールド（`const` を除く）

以下の点に注意してください。

- アクセサーのアクセシビリティは、アクセサー自体に修飾子がなければプロパティのアクセシビリティとなります。
- `protected` / `private protected` / `private` のアクセサー・フィールドは違反となりません。
- クラス自体のアクセシビリティ（`internal` クラスかどうか）は問いません。
- 明示的なインターフェイス実装のプロパティは対象外です。
- 違反はそのメンバーを宣言しているクラスで報告されます。

本規則はアセンブリのアーキテクチャ層の設定（`ArchitectureLayerAttribute`）に関係なく検証されます。

## 規則の説明

エンティティの状態の変更は操作（メソッド）により行われるべきです。
公開セッターが実装されている場合、状態変更ルールのようなドメイン知識がエンティティ外部に流出し、条件判定・値の設定などのドメインロジックが複数箇所に点在することでコードの保守性が低下する恐れがあります。

`init` アクセサーもオブジェクト初期化子によってエンティティ外部から任意の値を設定できるため、違反となります。
同一アセンブリ内の他のアーキテクチャ層から状態を書き換えられることを防ぐため、`internal` のセッターも違反となります。

## 違反の修正方法

公開セッターでエンティティの状態を変更する代わりに、操作（メソッド）を使用してください。
セッターのアクセシビリティは `private` に変更してください。フィールドの場合は `private` にするか、`readonly` にしてください。

コード修正ではプロパティのセッター（`set` / `init`）を `private set` に変更します。

## 例

```csharp
public class TodoItem : EntityBase<UuidV7>
{
    // Violates DFR0003
    public bool IsDone { get; set; }

    ...
}
```

```csharp
public class TodoItem : EntityBase<UuidV7>
{
    // Does not violate DFR0003
    public bool IsDone { get; private set; }

    public void Finish()
    {
        if (IsDone)
        {
            throw new DomainException(ErrorType.PreconditionFailed, "This item is already finished.");
        }
        IsDone = true;
    }
}
```

## 警告を抑制する状況

一般に、この規則による警告は抑制しないでください。

## 警告を抑制する

単一の違反を抑制するだけの場合は、ソース ファイルにプリプロセッサ ディレクティブを追加して無効にしてから、規則をもう一度有効にします。

```csharp
#pragma warning disable DFR0003
// 規則に違反するコード
#pragma warning restore DFR0003
```

ファイル、フォルダー、プロジェクトの規則を無効にするには、その重要度を `none` に設定し、[設定ファイル](https://learn.microsoft.com/ja-jp/dotnet/fundamentals/code-analysis/configuration-files) で適用します。

```ini
[*.cs]
dotnet_diagnostic.DFR0003.severity = none
```
