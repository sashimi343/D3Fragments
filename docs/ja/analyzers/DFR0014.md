# DFR0014: リポジトリで変更追跡を無効にしないでください

| プロパティ | 値 |
|---|---|
| 規則 ID | DFR0014 |
| タイトル | リポジトリで変更追跡を無効にしないでください |
| 既定の重大度 | Warning |
| 修正が破壊的か非破壊的か | 非破壊的 |
| コード修正 | なし |

## 原因

リポジトリの実装クラス（モジュールレイヤーが `Infrastructure_RepositoryImplementation` のクラス）で、EF Core の以下のメソッドが呼び出されています。
モジュールレイヤー名、およびモジュールレイヤーの判定方法に関する詳細は[モジュールレイヤー](../guide/01-architecture.md#モジュールレイヤー)を参照してください。

- `AsNoTracking()`
- `AsNoTrackingWithIdentityResolution()`
- `AsTracking(QueryTrackingBehavior)`（引数に定数で `QueryTrackingBehavior.TrackAll` 以外を指定した場合）

以下の点に注意してください。

- リポジトリ以外のクラス（クエリサービス等）での呼び出しは違反となりません。
- 共通の拡張メソッド等の内部で呼び出している場合は検知できません。
- `DbContextOptionsBuilder.UseQueryTrackingBehavior` による既定の追跡動作の変更は対象外です。

この規則は、呼び出し元のアセンブリに `ArchitectureLayerAttribute` が設定されている場合にのみ検証されます。

## 規則の説明

リポジトリは集約を変更するために取得する場所です。D3Fragments では、取得済みの集約への変更を Unit of Work が変更追跡によって保存します。
変更追跡を無効にして取得した集約を変更しても、エラーにならずに変更が失われます。

一覧表示など、変更を伴わない読み取り専用の問い合わせで性能が必要な場合は、リポジトリではなくクエリサービスに分離し、そこで `AsNoTracking()` を使用してください。
クエリサービスでの `AsNoTracking()` の利用は推奨される使い方です。

## 違反の修正方法

- 集約を取得するメソッドの場合は、`AsNoTracking()` 等の呼び出しを削除してください。
- 読み取り専用の問い合わせの場合は、メソッドをクエリサービスへ移動してください。

射影（`Select` で集約以外の型に変換する問い合わせ）の場合、`AsNoTracking()` は効果がないため、呼び出しを削除してください。

## 例

```csharp
public sealed class ShelfRepository(AppDbContext dbContext) : RepositoryBase<AppDbContext, Shelf>(dbContext), IShelfRepository
{
    // Violates DFR0014
    public Task<Shelf?> FindByNameAsync(ShelfName name, CancellationToken cancellationToken)
        => Set.AsNoTracking().SingleOrDefaultAsync(x => x.Name == name, cancellationToken);
}
```

```csharp
public sealed class ShelfRepository(AppDbContext dbContext) : RepositoryBase<AppDbContext, Shelf>(dbContext), IShelfRepository
{
    // Does not violate DFR0014
    public Task<Shelf?> FindByNameAsync(ShelfName name, CancellationToken cancellationToken)
        => Set.SingleOrDefaultAsync(x => x.Name == name, cancellationToken);
}

public sealed class ShelfQueryService(AppDbContext dbContext) : IShelfQueryService
{
    // Does not violate DFR0014: read-only queries belong to a query service
    public Task<Pager<ShelfSummary>> ListAsync(int pageNo, int pageSize, CancellationToken cancellationToken)
        => dbContext.Shelves.AsNoTracking()
            .OrderBy(x => x.Id)
            .Select(x => new ShelfSummary(x.Id, x.Name.Value))
            .ToPagedListAsync(pageNo, pageSize, cancellationToken);
}
```

## 警告を抑制する状況

一般に、この規則による警告は抑制しないでください。

## 警告を抑制する

単一の違反を抑制するだけの場合は、ソース ファイルにプリプロセッサ ディレクティブを追加して無効にしてから、規則をもう一度有効にします。

```csharp
#pragma warning disable DFR0014
// 規則に違反するコード
#pragma warning restore DFR0014
```

ファイル、フォルダー、プロジェクトの規則を無効にするには、その重要度を `none` に設定し、[設定ファイル](https://learn.microsoft.com/ja-jp/dotnet/fundamentals/code-analysis/configuration-files) で適用します。

```ini
[*.cs]
dotnet_diagnostic.DFR0014.severity = none
```
