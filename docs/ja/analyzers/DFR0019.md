# DFR0019: Query の Handler から Command を実行しないでください

| プロパティ | 値 |
|---|---|
| 規則 ID | DFR0019 |
| タイトル | Query の Handler から Command を実行しないでください |
| 既定の重大度 | Warning |
| 修正が破壊的か非破壊的か | 非破壊的 |
| コード修正 | なし |

## 原因

Query の Handler（`IQuery` を実装したリクエストの `IRequestHandler<TRequest, TResponse>` の実装）のコンストラクタ引数に、Command を実行する `IRequestExecutor<TRequest, TResponse>` または `IIsolatedRequestExecutor<TRequest, TResponse>` が指定されています。

以下の点に注意してください。

- プライマリコンストラクタを含む、すべてのインスタンスコンストラクタの引数が対象です。
- `IRequestExecutor<TRequest, TResponse>` を実装したクラスやインターフェースはすべて対象です。
- 実行するリクエストが Query の場合は対象外です。
- 実行するリクエストの型が型パラメータの場合は、Command か Query かを判定できないため対象外です。

この規則は、アセンブリに `ArchitectureLayerAttribute` が設定されている場合にのみ検証されます。

## 規則の説明

Query は状態を変更せずにデータを読み取るリクエストです。
Query の Handler が Command を実行すると、データを読み取るだけのはずの処理が DB を更新します。
呼び出し元からは、読み取りの処理を実行しただけで状態が変わったように見えます。

## 違反の修正方法

Query の Handler から Command を実行しないでください。次のどちらかで書き直します。

- 読み取りの前に必要な状態の変更（期限切れのデータの削除など）は、Query の中で行わずに、読み取りの条件で扱えないか検討してください。例えば、期限切れのデータを削除する代わりに、期限切れのデータを読み取りの対象から除きます。削除そのものはバッチ処理などで行います
- 状態の変更が必要な場合は、リクエストを Command にしてください

## 例

```csharp
public sealed class GetAvailableSeatsQueryHandler(IIsolatedRequestExecutor<DeleteExpiredReservationsCommand, int> deleteExpired)
    : IRequestHandler<GetAvailableSeatsQuery, IReadOnlyList<SeatDto>>
{
    // Violates DFR0019
}
```

```csharp
public sealed class GetAvailableSeatsQueryHandler(ISeatQueries seats, TimeProvider timeProvider)
    : IRequestHandler<GetAvailableSeatsQuery, IReadOnlyList<SeatDto>>
{
    // Does not violate DFR0019: 期限切れの予約を、空席の判定の条件で除く
    public Task<IReadOnlyList<SeatDto>> HandleAsync(GetAvailableSeatsQuery request, CancellationToken cancellationToken)
        => seats.FindAvailableAsync(timeProvider.GetUtcNow(), cancellationToken);
}
```

## 警告を抑制する状況

一般に、この規則による警告は抑制しないでください。

## 警告を抑制する

単一の違反を抑制するだけの場合は、ソース ファイルにプリプロセッサ ディレクティブを追加して無効にしてから、規則をもう一度有効にします。

```csharp
#pragma warning disable DFR0019
// 規則に違反するコード
#pragma warning restore DFR0019
```

ファイル、フォルダー、プロジェクトの規則を無効にするには、その重要度を `none` に設定し、[設定ファイル](https://learn.microsoft.com/ja-jp/dotnet/fundamentals/code-analysis/configuration-files) で適用します。

```ini
[*.cs]
dotnet_diagnostic.DFR0019.severity = none
```
