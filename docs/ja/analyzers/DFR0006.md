# DFR0006: TypeSafeEnum型のコンストラクタをクラス外部に公開しないでください

| プロパティ | 値 |
|---|---|
| 規則 ID | DFR0006 |
| タイトル | TypeSafeEnum型のコンストラクタをクラス外部に公開しないでください |
| 既定の重大度 | Warning |
| 修正が破壊的か非破壊的か | 破壊的 |
| コード修正 | あり（プライマリ コンストラクター以外のコンストラクタのみ） |

## 原因

本規則では、基底クラスとして `D3Fragments.TypeSafeEnum<TSelf, TKey>` を直接指定したクラスを「TypeSafeEnum 型」と呼びます。ただし、`TSelf` が型パラメーターであるクラス（ジェネリックな中間基底クラス）は TypeSafeEnum 型に含みません。

以下のいずれかに該当する場合に違反となります。

- TypeSafeEnum 型のインスタンス コンストラクターのアクセシビリティが `private` ではない（静的コンストラクターは対象外）
- TypeSafeEnum 型がプライマリ コンストラクターをもつ（プライマリ コンストラクターは常に `public` となるため）
- TypeSafeEnum 型を直接、または間接的に継承したクラスが、その TypeSafeEnum 型の `private` な入れ子クラスとして宣言されていない

本規則はアセンブリのアーキテクチャ層の設定（`ArchitectureLayerAttribute`）に関係なく検証されます。

## 規則の説明

クラス外部にコンストラクタを公開すると意図しない列挙子を生成可能になるため、コンストラクタの公開を避けるべきです。

値ごとに振る舞いを変える場合は、TypeSafeEnum 型を抽象クラスとし、`private` な入れ子クラスで各値を定義します。入れ子クラスを `private` 以外で宣言すると、入れ子クラスのコンストラクタを通じて外部から値を生成できてしまうため、違反となります。

## 違反の修正方法

コンストラクタの可視性をprivateに変更します。
プライマリ コンストラクターを使用している場合は、通常のコンストラクタに書き換えて `private` にします。
入れ子クラスで値を定義している場合は、入れ子クラスを `private` にします。

コード修正では、プライマリ コンストラクター以外のコンストラクタのアクセシビリティを `private` に変更します。

## 例

```csharp
public class UserType : TypeSafeEnum<UserType, int>
{
    public static readonly UserType Normal = new(0, "一般ユーザ");
    public static readonly UserType Admin = new(1, "管理ユーザ");

    // Violates DFR0006
    protected UserType(int key, string name) : base(key, name) {}
}

// Violates DFR0006
public class Color(string key) : TypeSafeEnum<Color, string>(key)
{
    public static readonly Color Red = new("red");
}
```

```csharp
public class UserType : TypeSafeEnum<UserType, int>
{
    public static readonly UserType Normal = new(0, "一般ユーザ");
    public static readonly UserType Admin = new(1, "管理ユーザ");

    // Does not violate DFR0006
    private UserType(int key, string name) : base(key, name) {}
}

public abstract class Shape : TypeSafeEnum<Shape, string>
{
    public static readonly Shape Circle = new CircleShape();

    private Shape(string key) : base(key) {}

    public abstract double Area(double size);

    // Does not violate DFR0006
    private sealed class CircleShape() : Shape("circle")
    {
        public override double Area(double size) => Math.PI * size * size;
    }
}
```

## 警告を抑制する状況

一般に、この規則による警告は抑制しないでください。

## 警告を抑制する

単一の違反を抑制するだけの場合は、ソース ファイルにプリプロセッサ ディレクティブを追加して無効にしてから、規則をもう一度有効にします。

```csharp
#pragma warning disable DFR0006
// 規則に違反するコード
#pragma warning restore DFR0006
```

ファイル、フォルダー、プロジェクトの規則を無効にするには、その重要度を `none` に設定し、[設定ファイル](https://learn.microsoft.com/ja-jp/dotnet/fundamentals/code-analysis/configuration-files) で適用します。

```ini
[*.cs]
dotnet_diagnostic.DFR0006.severity = none
```
