# DFR0007: 自己参照型パラメーター TSelf には宣言している型自身を指定してください

| プロパティ | 値 |
|---|---|
| 規則 ID | DFR0007 |
| タイトル | 自己参照型パラメーター TSelf には宣言している型自身を指定してください |
| 既定の重大度 | Warning |
| 修正が破壊的か非破壊的か | 破壊的 |
| コード修正 | なし |

## 原因

クラス・構造体・レコードの基底型リストに、以下のいずれかの型が直接指定されており、その型引数 `TSelf` に宣言している型自身以外の型が指定されています。

- `D3Fragments.TypeSafeEnum<TSelf, TKey>`（基底クラス）
- `D3Fragments.ValueObjectBase<TSelf, TPrimitive>`（基底クラス）
- `D3Fragments.IValueObject<TSelf, TPrimitive>`（実装インターフェース）

`TSelf` が型パラメーターである場合（ジェネリックな中間基底クラス等）は違反となりません。
宣言している型がジェネリック型の場合、自身の型パラメーターで構築した型（例：`class Foo<T> : TypeSafeEnum<Foo<T>, int>`）は宣言している型自身とみなします。

本規則はアセンブリのアーキテクチャ層の設定（`ArchitectureLayerAttribute`）に関係なく検証されます。

## 規則の説明

`TSelf` は派生クラス自身を表す型パラメーターです。基底クラスは `TSelf` が派生クラス自身であることを前提に実装されています。
例えば `TypeSafeEnum<TSelf, TKey>` はコンストラクタ内で自身を `TSelf` に型変換するため、`TSelf` に別の型を指定すると値の定義時に `InvalidCastException` が発生します。
型パラメーターの制約だけではこの誤りをコンパイル時に検出できないため、本規則で検出します。

## 違反の修正方法

`TSelf` に宣言している型自身を指定してください。

## 例

```csharp
public class UserType : TypeSafeEnum<UserType, int> { ... }

// Violates DFR0007
public class AdminType : TypeSafeEnum<UserType, int> { ... }
```

```csharp
// Does not violate DFR0007
public class AdminType : TypeSafeEnum<AdminType, int> { ... }
```

## 警告を抑制する状況

この規則による警告は抑制しないでください。

## 警告を抑制する

単一の違反を抑制するだけの場合は、ソース ファイルにプリプロセッサ ディレクティブを追加して無効にしてから、規則をもう一度有効にします。

```csharp
#pragma warning disable DFR0007
// 規則に違反するコード
#pragma warning restore DFR0007
```

ファイル、フォルダー、プロジェクトの規則を無効にするには、その重要度を `none` に設定し、[設定ファイル](https://learn.microsoft.com/ja-jp/dotnet/fundamentals/code-analysis/configuration-files) で適用します。

```ini
[*.cs]
dotnet_diagnostic.DFR0007.severity = none
```
