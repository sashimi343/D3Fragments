# DFR0005: 集約の一部を更新するリポジトリメソッドを定義しないでください

| プロパティ | 値 |
|---|---|
| 規則 ID | DFR0005 |
| タイトル | 集約の一部を更新するリポジトリメソッドを定義しないでください |
| 既定の重大度 | Warning |
| 修正が破壊的か非破壊的か | 破壊的 |
| コード修正 | なし |

## 原因

`D3Fragments.IRepository<TAggregate, TId>` インターフェースを直接、または間接的に継承したインターフェース（`IRepository<TAggregate>` を経由した継承を含む）において、引数の型に `TAggregate` 以外のエンティティ（`EntityBase<TId>` を直接、または間接的に継承したクラス）を含むメソッドが宣言されています。

引数の型の検査方法、および対象となるメソッドは [DFR0004](DFR0004.md) の戻り値の型の検査と同じです（`ref` / `out` / `in` / `params` 引数を含む）。違反は該当する引数ごとに報告されます。

更新用途のメソッドに限らず、検索条件として集約の一部のエンティティを受け取るメソッドも違反となります。検索条件にはエンティティではなく、そのIDを渡してください。

本規則はアセンブリのアーキテクチャ層の設定（`ArchitectureLayerAttribute`）に関係なく検証されます。

## 規則の説明

リポジトリ経由でのエンティティの更新は集約単位で実施されるべきです。
集約の一部のエンティティのみを更新するメソッドを実装した場合、集約の整合性が壊れる可能性があります。

## 違反の修正方法

集約の一部ではなく、集約ルート自体を引数として渡すように変更してください。
検索条件として利用している場合は、エンティティの代わりにIDを渡すように変更してください。

## 例

```csharp
public interface IBookshelfRepository : IRepository<Bookshelf, UuidV7>
{
    // Violates DFR0005
    void UpdateBook(Book book);

    // Violates DFR0005
    Task<Bookshelf?> FindByBookAsync(Book book, CancellationToken cancellationToken);
}
```

```csharp
public interface IBookshelfRepository : IRepository<Bookshelf, UuidV7>
{
    // Does not violate DFR0005
    Task<Bookshelf?> FindByBookIdAsync(UuidV7 bookId, CancellationToken cancellationToken);
}
```

## 警告を抑制する状況

一般に、この規則による警告は抑制しないでください。

## 警告を抑制する

単一の違反を抑制するだけの場合は、ソース ファイルにプリプロセッサ ディレクティブを追加して無効にしてから、規則をもう一度有効にします。

```csharp
#pragma warning disable DFR0005
// 規則に違反するコード
#pragma warning restore DFR0005
```

ファイル、フォルダー、プロジェクトの規則を無効にするには、その重要度を `none` に設定し、[設定ファイル](https://learn.microsoft.com/ja-jp/dotnet/fundamentals/code-analysis/configuration-files) で適用します。

```ini
[*.cs]
dotnet_diagnostic.DFR0005.severity = none
```
