# DFR0015: 子エンティティを含む集約のリポジトリでは FindAsync をオーバーライドしてください

| プロパティ | 値 |
|---|---|
| 規則 ID | DFR0015 |
| タイトル | 子エンティティを含む集約のリポジトリでは FindAsync をオーバーライドしてください |
| 既定の重大度 | Warning |
| 修正が破壊的か非破壊的か | 非破壊的 |
| コード修正 | なし |

## 原因

`RepositoryBase<TContext, TAggregate, TId>`（または `RepositoryBase<TContext, TAggregate>`）を継承した非抽象クラスが `FindAsync` をオーバーライドしておらず、かつ集約ルート `TAggregate` が子エンティティ（`Entity<TId>` を継承し、`AggregateRoot<TId>` を継承しない型）を参照するプロパティを持っています。

以下の点に注意してください。

- プロパティの型は配列の要素型・ジェネリック型の型引数（`IReadOnlyList<T>` 等）も再帰的に検査します。
- 他の集約ルートを参照するプロパティは対象外です。
- `RepositoryBase` との間にある中間の基底クラスで `FindAsync` をオーバーライドしている場合は違反となりません。
- オーバーライドした `FindAsync` で実際に子エンティティを `Include` しているかどうかは検証しません。
- `FindAsync` 以外の独自の取得メソッドは対象外です。

## 規則の説明

`RepositoryBase` の既定の `FindAsync` は `DbSet.FindAsync` で集約ルートだけを読み込み、子エンティティを読み込みません。
集約は整合性の単位であり、子エンティティが読み込まれていない集約を操作すると、不変条件の判定を誤ったり、子エンティティの変更が失われたりします。

## 違反の修正方法

`FindAsync` をオーバーライドし、`Include` で子エンティティを読み込んでください。

## 例

```csharp
public sealed class Shelf : AggregateRoot
{
    private readonly List<ShelfItem> _items = [];

    public IReadOnlyList<ShelfItem> Items => _items;
}

// Violates DFR0015
public sealed class ShelfRepository(AppDbContext dbContext) : RepositoryBase<AppDbContext, Shelf>(dbContext), IShelfRepository;
```

```csharp
// Does not violate DFR0015
public sealed class ShelfRepository(AppDbContext dbContext) : RepositoryBase<AppDbContext, Shelf>(dbContext), IShelfRepository
{
    public override Task<Shelf?> FindAsync(UuidV7 id, CancellationToken cancellationToken)
        => Set.Include(x => x.Items).SingleOrDefaultAsync(x => x.Id == id, cancellationToken);
}
```

## 警告を抑制する状況

`OnModelCreating` で子エンティティへのナビゲーションに `AutoInclude()` を設定している場合など、既定の `FindAsync` で子エンティティが読み込まれる場合は、警告を抑制しても問題ありません。

## 警告を抑制する

単一の違反を抑制するだけの場合は、ソース ファイルにプリプロセッサ ディレクティブを追加して無効にしてから、規則をもう一度有効にします。

```csharp
#pragma warning disable DFR0015
// 規則に違反するコード
#pragma warning restore DFR0015
```

ファイル、フォルダー、プロジェクトの規則を無効にするには、その重要度を `none` に設定し、[設定ファイル](https://learn.microsoft.com/ja-jp/dotnet/fundamentals/code-analysis/configuration-files) で適用します。

```ini
[*.cs]
dotnet_diagnostic.DFR0015.severity = none
```
